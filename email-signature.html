How to install this signature

Gmail:
Settings (gear icon) → See all settings → General tab → Signature → Create new.
Click the </> (HTML source) icon in the signature editor, paste the HTML between the two comment markers above, click OK.

Outlook (desktop):
File → Options → Mail → Signatures → New.
Click the HTML file icon or paste directly. Alternatively, save this file, then drag it into the signature editor.

Apple Mail:
Mail → Preferences → Signatures → Create a new signature, then right-click the signature and choose “Open in Editor” to paste HTML.
